# QuietQQliu 0.2.3

面向 QQ浏览器 Android（`com.tencent.mtt`）的 LSPosed 去广告模块，适配
**20.7.5.5035（versionCode 20750500）**。

## 本版内容

- 新增 **AD-13 热启动全屏/悬浮广告**：
  - 热启动后不再弹出全屏倒计时广告；
  - 倒计时结束/关闭后不会缩成右下角的悬浮倒计时挂件；
  - 覆盖 `CommonMaskService`、全屏 mask dialog、挂件通知与首页倒计时挂件入口；
  - 其他普通挂件（下载、文本、游戏等）不受影响。
- 保留 0.2.2 的全部能力：开屏、信息流、我的、小说悦读卡、听书、激励视频、
  下载直连、Hippy 广告网络拦截等。
- 锚点检查器更新为 107 条。

## 安装

1. 安装 APK；
2. 在支持 libxposed API 102 的 LSPosed / NPatch 中启用模块；
3. 作用域勾选 **QQ浏览器（`com.tencent.mtt`）**；
4. 强制停止 QQ浏览器后重新打开。

## 说明与边界

- 适配基线为 20.7.5.5035；其他版本可能因类名/接口漂移导致部分 hook 失效，
  失败会 fail-open，不会导致宿主崩溃。
- AD-13 只拦截该套 mask 倒计时广告链路；如果某个版本把广告换成另一套实现，
  诊断页会显示 AD-13 无命中，可按 `tools/check-anchors.py` 重新定位。
- 服务端直接拼接进正文/H5 的广告无法保证 100% 消除。
- 本项目仅用于学习研究与个人设备，与腾讯官方无任何关联。
