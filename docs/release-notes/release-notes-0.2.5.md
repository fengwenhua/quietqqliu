# QuietQQliu 0.2.5

面向 QQ浏览器 Android（`com.tencent.mtt`）的 LSPosed 去广告模块，适配
**20.7.5.5035（versionCode 20750500）**。

## 本版内容

- 小说频道「我的」页轮播位整体移除：
  - 预加载数据中的 `BANNER` 卡片直接删除；
  - 通过 Hippy DOM 把轮播卡片的 FlexNode 高度改成 0，页面重新布局，
    「我的小说」等后续内容自动上移，不再留下整块空白；
  - 原生卡片 View 同时隐藏，作为兜底。
- 轮播中的第三方广告、运营位和 VIP 卡一并移除。
- 保留 0.2.4 的 `batch_get_ads` 拦截、0.2.3 的热启动全屏/悬浮广告拦截与其余全部能力。
- 锚点检查器更新为 109 条。

## 安装

1. 安装 APK；
2. 在支持 libxposed API 102 的 LSPosed / NPatch 中启用模块；
3. 作用域勾选 **QQ浏览器（`com.tencent.mtt`）**；
4. 强制停止 QQ浏览器后重新打开。

## 说明

- 适配基线为 20.7.5.5035；其他版本可能因类名/接口漂移导致部分 hook 失效，
  失败会 fail-open，不会导致宿主崩溃。
- 本项目仅用于学习研究与个人设备，与腾讯官方无任何关联。
